# com.tailf.dp.annotations

Annotations and proxy helper classes for callbacks.


 The annotation classes are used to annotate methods in any POJO that should
 act as a callback. The signature of the annotated method must coincide with
 that of the respective interface method otherwise an exception is thrown at
 registration of the callback.
