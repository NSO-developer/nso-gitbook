# Java API Reference

| Package | Description |
| --- | --- |
| [`com.tailf.cdb`](com/tailf/cdb/README.md) | Package with methods for connecting to the configuration database. |
| [`com.tailf.conf`](com/tailf/conf/README.md) | Data types and utilities for communication with the server. |
| [`com.tailf.dp`](com/tailf/dp/README.md) | Data provider API package, for implementation of callbacks for validations, actions, transformation etc. |
| [`com.tailf.dp.annotations`](com/tailf/dp/annotations/README.md) | Annotations and proxy helper classes for callbacks. |
| [`com.tailf.dp.proto`](com/tailf/dp/proto/README.md) | Callback method types for respective callback type. |
| [`com.tailf.dp.services`](com/tailf/dp/services/README.md) | Service callback specific context and utilities. |
| [`com.tailf.ha`](com/tailf/ha/README.md) | Package for setup and control of High Availability cluster nodes. |
| [`com.tailf.maapi`](com/tailf/maapi/README.md) | MAAPI is an API which provides full access to the systems internal transaction engine. |
| [`com.tailf.navu`](com/tailf/navu/README.md) | NAVU (Navigation Utilities) is an API which provides increased accessibility to the ConfD/NCS populated data model tree: NAVU-Tree. |
| [`com.tailf.navu.traversal`](com/tailf/navu/traversal/README.md) | Utility package for traversing the NAVU tree (or a subset thereof) using the NAVU API. |
| [`com.tailf.ncs`](com/tailf/ncs/README.md) | NCS Java machine management and control of Services, Neds, callbacks and Applications |
| [`com.tailf.ncs.alarmman`](com/tailf/ncs/alarmman/README.md) | The Alarm Manager provides utilities for management of the NCS alarm list. |
| [`com.tailf.ncs.alarmman.common`](com/tailf/ncs/alarmman/common/README.md) | The Common Alarm Management package contains common definitions that are used within the alarm manager. |
| [`com.tailf.ncs.alarmman.consumer`](com/tailf/ncs/alarmman/consumer/README.md) | The Alarm Manager consumer package provides support for subscription to alarms in the NCS Alarm list. |
| [`com.tailf.ncs.alarmman.producer`](com/tailf/ncs/alarmman/producer/README.md) | The Alarm Manager producer package provides support for injection of alarms into the NCS Alarm list. |
| [`com.tailf.ncs.annotations`](com/tailf/ncs/annotations/README.md) | Annotations and proxy helper classes for callbacks. |
| [`com.tailf.ncs.maapi`](com/tailf/ncs/maapi/README.md) |  |
| [`com.tailf.ncs.ns`](com/tailf/ncs/ns/README.md) | This package comprises name-space classes generated from the NCS YANG models. |
| [`com.tailf.ncs.proto`](com/tailf/ncs/proto/README.md) | Callback method types for respective callback type. |
| [`com.tailf.ncs.snmp.snmp4j`](com/tailf/ncs/snmp/snmp4j/README.md) | NCS snmp4j support package |
| [`com.tailf.ncs.template`](com/tailf/ncs/template/README.md) | Package implementing Template processing commands sent to NSO for processing. |
| [`com.tailf.ned`](com/tailf/ned/README.md) | Network Element Drivers package |
| [`com.tailf.notif`](com/tailf/notif/README.md) | Package for subscription to asynchronous events. |
| [`com.tailf.progress`](com/tailf/progress/README.md) |  |
| [`com.tailf.proto`](com/tailf/proto/README.md) | Package containing java class representations of Erlang datatypes or terms which are used internally in the communication between the Library and ConfD/NCS. |
| [`com.tailf.util`](com/tailf/util/README.md) | Utility classes for representing compiled ConfNamespaces. |
